3.1. cURL (Streaming):
curl -X POST "https://router.danlapkythuattonghop-hanoi.com.vn/v1/chat/completions" \
  -H "Authorization: Bearer <API_KEY_CỦA_BẠN>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.6-luna",
    "messages": [
      {"role": "system", "content": "Bạn là trợ lý AI chuyên nghiệp."},
      {"role": "user", "content": "Viết thuật toán QuickSort bằng Python ngắn gọn kèm giải thích."}
    ],
    "stream": true
  }'

3.2. Python (Dùng thư viện chính thức openai):
```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-9r-xxxx",
    base_url="https://router.danlapkythuattonghop-hanoi.com.vn/v1"
)

response = client.chat.completions.create(
    model="gpt-5.6-luna",
    messages=[
        {"role": "system", "content": "Bạn là lập trình viên chuyên nghiệp."},
        {"role": "user", "content": "Giải thích Decorator trong Python kèm ví dụ."}
    ],
    stream=True
)

for chunk in response:
    content = chunk.choices[0].delta.content or ""
    print(content, end="", flush=True)
print()
```

3.3. Python (Dùng thư viện requests tiêu chuẩn):
```python
import requests
import json

URL = "https://tuansuapi.store/v1/chat/completions"
headers = {
    "Authorization": "Bearer <API_KEY_CỦA_BẠN>",
    "Content-Type": "application/json"
}
payload = {
    "model": "deepseek-v4.1-flash",
    "messages": [{"role": "user", "content": "Giải bài toán tháp Hà Nội với 4 đĩa."}],
    "stream": True
}

response = requests.post(URL, headers=headers, json=payload, stream=True)
for line in response.iter_lines():
    if line:
        decoded = line.decode('utf-8')
        if decoded.startswith("data: ") and decoded != "data: [DONE]":
            chunk = json.loads(decoded[6:])
            content = chunk["choices"][0]["delta"].get("content", "")
            print(content, end="", flush=True)
print()
```

PHẦN 5: HƯỚNG DẪN TẠO ẢNH TỪ VĂN BẢN (KHÔNG CÓ ẢNH THAM CHIẾU)
================================================================================
Sử dụng khi bạn muốn vẽ một bức ảnh hoàn toàn mới chỉ từ câu lệnh mô tả (Prompt).

1. ENDPOINT:
   POST https://tuansuapi.store/v1/images/generations

2. CÁC THAM SỐ CHÍNH (BODY JSON):
   - model: "gpt-image-2" (hoặc "gpt-image-2.5-flare", "gemini-3.1-flash-image-preview")
   - prompt: "Câu mô tả chi tiết hình ảnh bạn muốn tạo..."
   - n: 1 (số lượng ảnh tạo ra)
   - size: "1024x1024" (hoặc "1024x1792" ảnh dọc, "1792x1024" ảnh ngang)
   - response_format: "url" (trả về link tải ảnh) HOẶC "b64_json" (trả về chuỗi base64)

3. MẪU REQUEST cURL:
curl -X POST https://tuansuapi.store/v1/images/generations \
  -H "Authorization: Bearer <API_KEY_CỦA_BẠN>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Một chú rồng nhỏ dễ thương phong cách 3D Pixar, nền rừng tuyết lung linh, 8k",
    "n": 1,
    "size": "1024x1024"
  }'

Phản hồi mẫu từ API:
{
  "created": 1789634367,
  "data": [
    {
      "url": "https://img.apimatou.cc/i/example_image_123.png",
      "revised_prompt": "Một chú rồng nhỏ dễ thương..."
    }
  ]
}

4. CODE PYTHON HOÀN CHỈNH TỰ ĐỘNG TẢI VÀ LƯU ẢNH:
```python
import requests

API_KEY = "sk-9r-xxxx"
URL = "https://tuansuapi.store/v1/images/generations"

headers = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json"
}

payload = {
    "model": "gpt-image-2",
    "prompt": "Cyberpunk city night view, neon lights, ultra realistic 8k, cinematic lighting",
    "n": 1,
    "size": "1024x1024"
}

response = requests.post(URL, headers=headers, json=payload, timeout=60)
result = response.json()

if "data" in result and len(result["data"]) > 0:
    item = result["data"][0]
    if "url" in item:
        img_url = item["url"]
        print(f"Ảnh đã tạo thành công: {img_url}")
        img_data = requests.get(img_url).content
        with open("anh_tao_moi.png", "wb") as f:
            f.write(img_data)
        print("Đã lưu vào file anh_tao_moi.png")
    elif "b64_json" in item:
        import base64
        img_bytes = base64.b64decode(item["b64_json"])
        with open("anh_tao_moi.png", "wb") as f:
            f.write(img_bytes)
        print("Đã lưu ảnh từ base64 vào file anh_tao_moi.png")
else:
    print("Lỗi tạo ảnh:", result)
```

PHẦN 6: HƯỚNG DẪN SỬA ẢNH (CÓ 1 ẢNH THAM CHIẾU - IMAGE-TO-IMAGE)
================================================================================
Sử dụng khi bạn đã có 1 bức ảnh gốc và muốn:
- Thay đổi trang phục, màu tóc, khuôn mặt của nhân vật.
- Thay đổi bối cảnh đằng sau (từ phòng khách ra bãi biển, vũ trụ...).
- Chuyển đổi phong cách (từ ảnh chụp thật sang phong cách anime/hoạt hình 3D/sơn dầu).

1. ENDPOINT:
   POST https://tuansuapi.store/v1/images/edits

2. CÁCH 1: GỬI QUA JSON DATA URL (KHUYÊN DÙNG, TIỆN DỤNG NHẤT):
Ảnh gốc được mã hóa thành dạng Base64 Data URL: "data:image/png;base64,iVBORw0KGgo..."

Ví dụ cURL:
curl -X POST https://tuansuapi.store/v1/images/edits \
  -H "Authorization: Bearer <API_KEY_CỦA_BẠN>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Chuyển nhân vật trong bức ảnh này sang phong cách tranh sơn dầu cổ điển",
    "image": "data:image/png;base64,<CHUỖI_BASE64_ẢNH_GỐC>",
    "n": 1,
    "size": "1024x1024"
  }'

3. CÁCH 2: GỬI MULTIPART FORM-DATA (UPLOAD FILE TRỰC TIẾP):
curl -X POST https://tuansuapi.store/v1/images/edits \
  -H "Authorization: Bearer <API_KEY_CỦA_BẠN>" \
  -F "model=gpt-image-2" \
  -F "prompt=Thêm một chiếc kính râm phong cách ngầu cho nhân vật" \
  -F "image=@anh_goc.png;type=image/png" \
  -F "size=1024x1024"

4. CODE PYTHON HOÀN CHỈNH SỬA ẢNH TỪ FILE CÓ SẴN TRONG MÁY:
```python
import requests
import base64

API_KEY = "sk-9r-xxxx"
URL = "https://tuansuapi.store/v1/images/edits"

def file_to_data_uri(path):
    with open(path, "rb") as f:
        encoded = base64.b64encode(f.read()).decode("utf-8")
    ext = path.split(".")[-1].lower()
    mime = "image/jpeg" if ext in ["jpg", "jpeg"] else "image/png"
    return f"data:{mime};base64,{encoded}"

anh_goc_uri = file_to_data_uri("anh_chan_dung.png")

payload = {
    "model": "gpt-image-2",
    "prompt": "Giữ nguyên nét mặt nhân vật, thay đổi nền phía sau thành quán cà phê vintage ngập nắng",
    "image": anh_goc_uri,
    "size": "1024x1024"
}

headers = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json"
}

res = requests.post(URL, headers=headers, json=payload, timeout=90)
data = res.json()
print("Kết quả:", data)
```

PHẦN 7: HƯỚNG DẪN GHÉP & KẾT HỢP NHIỀU ẢNH THAM CHIẾU (2+ ẢNH)
================================================================================
ĐÂY LÀ TÍNH NĂNG CỰC KỲ MẠNH MẼ CỦA MODEL `gpt-image-2`:
Bạn có thể truyền vào 2 (hoặc 3, 4) bức ảnh khác nhau để AI kết hợp:
- Ảnh 1: Khuôn mặt hoặc nhân vật mẫu.
- Ảnh 2: Bối cảnh, tư thế hoặc phong cách nghệ thuật mong muốn.
-> AI sẽ trích xuất đặc trưng của cả 2 ảnh và kết hợp hài hòa ra bức ảnh mới!

1. ENDPOINT:
   POST https://tuansuapi.store/v1/images/edits

2. ĐỊNH DẠNG BODY JSON:
Truyền mảng danh sách các ảnh vào trường "image" hoặc "images":
{
  "model": "gpt-image-2",
  "prompt": "Lấy nhân vật nữ từ ảnh thứ nhất, đặt vào khung cảnh lễ hội hoa anh đào từ ảnh thứ hai, phong cách điện ảnh sắc nét",
  "image": [
    "data:image/png;base64,<BASE64_ẢNH_1>",
    "data:image/png;base64,<BASE64_ẢNH_2>"
  ],
  "size": "1024x1024"
}
*(Ghi chú: Gateway tự động hỗ trợ cả key "image": [...] lẫn "images": [...])*

3. CODE PYTHON ĐẦY ĐỦ GHÉP 2 ẢNH THAM CHIẾU:
```python
import requests
import base64

API_KEY = "sk-9r-xxxx"
URL = "https://tuansuapi.store/v1/images/edits"

def image_to_base64_uri(file_path):
    with open(file_path, "rb") as f:
        b64 = base64.b64encode(f.read()).decode("utf-8")
    ext = file_path.split(".")[-1].lower()
    mime = "image/jpeg" if ext in ["jpg", "jpeg"] else "image/png"
    return f"data:{mime};base64,{b64}"

# Chuẩn bị 2 ảnh tham chiếu
uri_nhan_vat = image_to_base64_uri("nhan_vat_mau.png")  # Ảnh 1: Nhân vật
uri_boi_canh = image_to_base64_uri("boi_canh_mau.png")   # Ảnh 2: Bối cảnh / phong cách

payload = {
    "model": "gpt-image-2",
    "prompt": "Kết hợp hài hòa hai bức ảnh tham chiếu: Đặt nhân vật ở ảnh thứ nhất vào bối cảnh vũ trụ ở ảnh thứ hai, giữ trọn vẹn đặc điểm trang phục và màu sắc",
    "image": [uri_nhan_vat, uri_boi_canh],
    "n": 1,
    "size": "1024x1024"
}

headers = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json"
}

print("Đang gửi yêu cầu ghép 2 ảnh...")
response = requests.post(URL, headers=headers, json=payload, timeout=120)
res_data = response.json()

if "data" in res_data and len(res_data["data"]) > 0:
    item = res_data["data"][0]
    if "url" in item:
        print("Link ảnh kết quả:", item["url"])
        with open("anh_ghep_ket_qua.png", "wb") as f:
            f.write(requests.get(item["url"]).content)
    elif "b64_json" in item:
        with open("anh_ghep_ket_qua.png", "wb") as f:
            f.write(base64.b64decode(item["b64_json"]))
    print("✅ Đã lưu kết quả thành công vào file anh_ghep_ket_qua.png!")
else:
    print("❌ Thất bại:", res_data)
```

PHẦN 11: CÁC LƯU Ý KỸ THUẬT QUAN TRỌNG
================================================================================

1. LƯU Ý SỐNG CÒN VỀ STREAM & TIMEOUT:
   - Với các model suy luận sâu như `gpt-5.6-luna`, `claude-opus-5`, `deepseek-v4-pro`, AI cần
     thời gian suy nghĩ (reasoning) từ 20 đến 45 giây trước khi ra câu trả lời hoàn chỉnh.
   - Hầu hết các ứng dụng (NextChat, Chatbox, thư viện code) mặc định Request Timeout là 30s.
   - NẾU TẮT STREAM ("stream": false): Trong suốt 30s suy luận, server chưa gửi byte nào về,
     phần mềm client sẽ tưởng server bị treo và TỰ ĐỘNG NGẮT KẾT NỐI (dẫn đến lỗi Status 499 / 524)!
   - KHI BẬT STREAM ("stream": true): Hệ thống phát nhịp tim (heartbeat) và gửi từng token về
     client liên tục, đảm bảo kết nối mượt mà, nhanh và không bao giờ bị timeout.
   - Khuyến nghị: Luôn cấu hình Request Timeout của client từ 60s - 120s và luôn bật STREAM.

2. CƠ CHẾ CACHE TOKEN (PROMPT CACHING):
   - Hệ thống tự động cache ngữ cảnh (prompt cache) đối với các chuỗi prompt dài.
   - Khi cache hit, giá token đầu vào sẽ được giảm cực mạnh (chỉ từ 50đ - 180đ/1M token thay vì giá đầy đủ).

3. QUẢN LÝ HẠN MỨC & NẠP VÍ TỰ ĐỘNG:
   - Bạn có thể kiểm tra số dư và lịch sử chi tiết từng request tại Bot Telegram hoặc qua:
     Web Portal: https://tuansuapi.store/portal (đăng nhập bằng mã API key).

11.3. Mẫu Python gọi trực tiếp:
```python
import requests

API_KEY = "sk-9r-xxxx"
BASE_URL = "https://tuansuapi.store/v1"
HEADERS = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json"
}

# 1. Lấy danh sách sản phẩm còn hàng
res = requests.get(f"{BASE_URL}/gmail/products", headers=HEADERS)
products = res.json().get("products", [])
print(f"Tổng số loại: {len(products)}")

# 2. Mua 2 tài khoản loại 75441
order = requests.post(f"{BASE_URL}/gmail/buy", json={
    "product_id": "75441",
    "quantity": 2
}, headers=HEADERS).json()

if order.get("status") == "success":
    print("Mua thành công! Danh sách tài khoản:")
    for acc in order["order"]["accounts"]:
        print(" ->", acc)
else:
    print("Lỗi:", order.get("message"))
```

PHẦN 13: XỬ LÝ SỰ CỐ VÀ CÁC CÂU HỎI THƯỜNG GẶP (FAQ)
================================================================================

Hỏi: Tôi gọi model `gpt-5.6-luna` bị lỗi đỏ status 499 hoặc 524?
Đáp: Lỗi 499/524 là do client của bạn tự ngắt kết nối khi hết 30s timeout trong lúc AI đang suy luận.
     Hãy BẬT "stream": true hoặc tăng Request Timeout trong app của bạn lên 90s - 120s.

Hỏi: Muốn ghép 2 ảnh thì ảnh kích thước thế nào?
Đáp: Bạn có thể dùng ảnh PNG, JPG dung lượng dưới 10MB mỗi ảnh. Hệ thống sẽ tự chuẩn hóa
     và sinh ra ảnh vuông 1024x1024 (hoặc tỉ lệ bạn chọn trong tham số `size`).

Hỏi: Kiểm tra số dư tài khoản ở đâu?
Đáp: Mở Bot Telegram bán hàng của shop -> Nhấn menu "API CỦA TÔI" hoặc "VÍ & SỐ DƯ",
     hoặc truy cập Web Portal: https://tuansuapi.store/portal nhập mã key để xem chi tiết.

Hỏi: Khi dùng hết tiền thì nạp thêm bằng cách nào?
Đáp: Vào Bot Telegram hoặc Web Portal -> Chọn Nạp thêm tiền cho API bằng mã VietQR chuyển khoản
     tự động (SePay), hệ thống tự động cộng tiền trong 10-30 giây hoạt động 24/7.
